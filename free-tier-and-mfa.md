# Azure Free Tier Services and MFA Configuration

## Azure Free Tier Services Matrix

The following table summarizes selected Azure Free Tier services and their usage limits.

| Service                | Free Tier Limit                            |
| ---------------------- | ------------------------------------------ |
| Virtual Machines (B1s) | Limited monthly hours (varies by offer)    |
| Azure Blob Storage     | Up to 5 GB locally redundant storage (LRS) |
| Azure Files            | Limited storage allocation                 |
| Azure SQL Database     | Limited database size and usage            |
| Azure Cosmos DB        | Limited throughput and storage             |
| Azure Functions        | 1 million requests per month               |
| Azure App Service      | Free tier hosting available                |
| Azure Bandwidth        | Limited outbound data transfer             |
| Azure Advisor          | Included at no additional cost             |
| Azure Cost Management  | Included at no additional cost             |

**Note:** Free Tier allocations can vary depending on the Azure subscription type. Users should regularly review their usage in Cost Management to avoid exceeding limits.

## Multi-Factor Authentication (MFA) Configuration

### Objective

Multi-Factor Authentication (MFA) was enabled to enhance account security by requiring a second form of verification in addition to the account password.


### Security Benefits

* Protects against password theft.
* Reduces the risk of unauthorized access.
* Provides an additional verification layer.
* Aligns with Azure security best practices.

## Conclusion

Azure Cost Management, Free Tier monitoring, and Multi-Factor Authentication were configured and reviewed to improve governance, cost control, and security within the Azure environment.
